Integration guide · Newsletter Management

Account Hub becomes the front door for the portal.

The portal checks passwords and the CVE_SYSTEM role with Account Hub at sign-in, then stores local roles and ownership records in MongoDB. A local bootstrap administrator retains full configuration access.

02 · The merge

What changes in the existing system

A

Account Hub owns authentication

/login sends the submitted username and Base64-encoded password to Account Hub over HTTPS.

B

The portal checks eligibility

After login, the portal checks tokens and requires roles[].roleName to contain CVE_SYSTEM.

C

Local roles control access

New Hub users are user by default. The local admin can assign sub_admin or user; only the bootstrap account is admin.

03 · Runtime flow

Hub verification at sign-in, local authorization afterward

1

Credentials

The browser submits username and password to /login.

2

Hub login

Flask calls the Account Hub password endpoint. Wrong credentials block sign-in.

3

Check role

Flask calls token-check, rejects inactive or anonymous accounts, and requires CVE_SYSTEM in roles[].roleName.

4

Create profile

The portal stores the Hub UID and creates a local user profile if needed.

5

Authorize locally

Each protected request reads the current local role and disabled state. The admin can change roles in the panel.

6

Local logout

/logout clears the portal session.

04 · Configuration

Enable it only after the test endpoints work

Use the test Account Hub endpoints first. Keep each full endpoint URL explicit; the portal does not guess or append an /auth path.

ACCOUNT_HUB_ENABLED=true
ACCOUNT_HUB_LOGIN_URL=https://test.example/auth/user/oauth/login
ACCOUNT_HUB_TOKEN_CHECK_URL=https://test.example/token/check
ACCOUNT_HUB_TIMEOUT_SECONDS=5
Important: Hub credentials and tokens are checked only at sign-in. An active portal session lasts up to 12 hours unless the local account is disabled or the user signs out. A slider CAPTCHA may be required after repeated failures; the portal accepts a verification token but does not provide the slider widget.
